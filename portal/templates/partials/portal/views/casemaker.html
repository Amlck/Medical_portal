Casemaker — CLI Only

Casemaker generates PowerPoint case presentations from medical record PDFs. It currently runs as a command-line tool with interactive prompts, so it isn't embedded here yet.

Quick start:

cd ~/Coding/Medical/Casemaker_project_powerpoint # Stage 1: Extract data from PDF python src/extractor.py # Stage 2: Generate PowerPoint python src/Casemaker.py

Place your medical record PDFs in input/scans/ before running.
